## ◆ About

Senior software engineer with **8+ years** building cross-stack systems — from enterprise **Identity & Access Management** platforms, to consumer marketplaces, to multi-tenant SaaS. Currently shipping at **Allianz Australia** across **Angular, Node.js, AWS** and **Identity Governance**.

Outside of $work I run **[ShareDeal](https://sharedealnow.com)** — a group-buying platform connecting Bangladeshi farmers directly with consumers — and continuously ship side-projects, from offline-first accounting (গণক) and a Bangladesh-first IAM platform (Porichoy) to a blockchain document registry.

```yaml
location:    Dhaka, Bangladesh  🇧🇩
focus:       Distributed systems · IAM · Mobile · Cloud-native SaaS
currently:   Scaling ShareDeal · Building Porichoy · Multi-tenant ERP
exploring:   Advanced Node internals · Riverpod · System design at scale
mantra:      "Ship. Listen. Iterate. Repeat."
```
